# Update Set Export

The ServiceNow application is captured in the **Loaner Laptop Desk** Update Set.

## Add the XML here

From ServiceNow:

1. Open the **Loaner Laptop Desk** Update Set.
2. Make sure all development changes are captured.
3. Export the Update Set as XML.
4. Rename the file to:

`Loaner_Laptop_Desk.xml`

5. Place it in this repository root.

Do **not** upload credentials, personal data, client/company-confidential information, or instance-specific secrets.
